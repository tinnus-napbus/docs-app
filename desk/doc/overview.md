The Docs app displays documentation for other installed apps. All apps are
automatically checked for docs, so if a particular app is not listed, it doesn't
have docs.

App publishers may include documentation for ordinary users and/or developers.

Appearance can be set to light, dark, or the browser's system preference from
the Settings page.
